# User Journey

## Entry Point

The user opens Health Journey and lands on the **Health Hub**.

The Health Hub provides an overview of the user's healthcare journey.

It includes:
- Upcoming appointments
- Pending reminders
- Recent documents
- AI Health Journey Snapshot
- Quick navigation

---

## Appointment Journey

1. View upcoming appointments.
2. Schedule a new appointment.
3. Reschedule if necessary (with a note).
4. Mark appointment as completed.
5. Appointment moves into history.

---

## Medical Timeline Journey

1. View chronological health timeline.
2. Open any event.
3. View reports, prescriptions, and notes related to that event.
4. Search previous medical history.

---

## Document Journey

1. Upload a report or prescription.
2. AI categorizes the document.
3. Document is linked to the correct timeline event.
4. User can retrieve it anytime.

---

## AI Navigator Journey

The user can ask questions like:

- What appointments are coming up?
- What documents do I need tomorrow?
- Show my last thyroid report.
- Summarize my recent healthcare activity.

The AI provides organizational assistance only.

---

## Visit Preparation Journey

Before every appointment, the user receives:

- Required documents
- Previous reports
- Personal notes
- Reminder checklist

---

## Journey Snapshot

The Health Hub continuously summarizes:

- Recent appointments
- Pending tasks
- Uploaded reports
- Upcoming visits

without providing medical advice.

---

## Family Management Journey

The user can switch between family members while keeping each healthcare journey separate.

---

## End Goal

The user always knows:

- What happened
- What is happening
- What comes next

without searching through scattered papers or messages.
